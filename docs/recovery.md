# 복구 가이드 (새 맥에서 다시 세우기)

이 저장소는 **설계 + 일반화한 예제**입니다. 운영하던 원본(기억 파일, 권한 설정, 개인 스크립트)은 담지 않으므로, 복구는 "원본 복원"이 아니라 **"설계대로 재구축 + 별도 백업에서 개인 데이터 복원"**입니다.

## 무엇이 어디에 있어야 하나
| 자산 | 이 저장소 | 다른 곳(각자 보관) |
|---|---|---|
| 구조·원칙·교훈·예제·템플릿 | ✅ | |
| 행동 규칙 원본(`CLAUDE.md`), 스킬 원본 | 템플릿만 | 작업 폴더 → **일일 백업** |
| 기억 파일(프로필·할 일) | ❌ (개인정보) | 작업 폴더 → **일일 백업** |
| 권한 설정, 스케줄러 설정 원본 | 템플릿만 | 작업 폴더 → **일일 백업** |
| 봇 토큰·허용 사용자 | ❌ | 비밀번호 관리자에 따로(코드·백업에 넣지 않음). 분실 시 **재발급** |

핵심 교훈: **백업 대상에 기억·설정이 반드시 들어 있어야 한다.** 저장소만으로는 복구가 안 된다. 예제 [`backup.sh`](../examples/backup.sh)는 작업 폴더를 클라우드 폴더에 날짜별로 복사한다.

## 복구 순서
1. 새 맥 준비: 잠자기 방지, Claude Code 로그인, tmux 설치.
2. 백업에서 작업 폴더 복원(`~/assistant`). 없다면 [따라 만들기](build-your-own.md)로 새로 시작.
3. 봇 토큰 **재발급**(분실·노출 의심 시) 후 권한 600 파일에 저장, 허용 사용자 재지정.
4. 스케줄러(LaunchAgent) 재등록: 경로의 계정명을 새 환경에 맞게 바꿔 설치.
5. **권한 재부여**: 새 맥은 앱 제어·전체 디스크·접근성 권한이 전부 초기화돼 있다. 필요한 기능만 전용 실행 파일에 다시 준다(L-098, L-083).
6. 점검: [`health-check.sh`](../examples/health-check.sh) 시험 실행 → 상시 세션이 메신저 요청에 답하는지 → 정기 보고 1회 수동 실행.
7. 첫 주는 "미확인" 목록([한계와 미확인](limitations.md))을 관찰 항목으로 두고 오탐·누락을 기록.

## 복구 시간 추정 [추정]
- 백업이 있을 때: 반나절(권한 재부여와 점검이 대부분)
- 백업이 없고 이 저장소만 있을 때: 며칠. 기억 파일은 복구 불가.
