# L-105 경로별로 도구를 나눈다: 무인은 차단, 대화형은 승인

**상황/증상:** 보안 점검에서 가장 현실적인 위협은 메일·메시지·웹 속 악성 지시(프롬프트 주입)로 판단됐다. 그런데 무인 정기 실행(메일·메시지를 읽고 일정·기억을 기록하는 작업)도 발송·삭제·웹 호출 도구를 쓸 수 있는 상태였다. 전부 막자니 사용자가 직접 시키는 발송·조사까지 막힌다.

**해결/방법:**
- 무인 실행에는 **도구 거부 목록**을 붙인다(발송·답장·전달, 메일 삭제·스팸 처리, 일정 삭제, 그리고 웹이 필요 없는 실행에서는 웹 검색·가져오기). 공통 목록을 한 파일에 두고 실행기가 읽는다.
- 도구가 필요 없는 작업(요약 전용)은 도구를 전부 끈다.
- 사용자가 시키는 세션은 막지 않고 **발송 도구를 "항상 승인"** 규칙으로 둔다. 요청하면 승인 한 번으로 진행된다.
- 시험: 거부한 도구를 쓰라고 시킨 실행이 막히는지, 허용한 정상 실행은 그대로 되는지 둘 다 확인.

**일반화:** "막을까 말까"가 아니라 "그 경로에 사람이 있는가"로 정한다. 사람이 없는 경로는 가능한 한 최소 도구만 주고, 사람이 있는 경로는 승인으로 통제한다. 무인 경로의 공격면(읽는 신뢰 못 할 내용 × 쓸 수 있는 도구)을 줄이는 것이 지시문으로 "따르지 마라"고 쓰는 것보다 확실하다.

**근거:** 2026-11-25 적용 후 시험(웹 검색 차단 확인, 정상 호출 확인). 실제 주입 공격에 대한 방어 효과는 검증하지 않았다 [미확인].
