# L-084 무인 작업자의 거짓 완료: 같은 이름의 폴더를 잘못 집는다

**상황/증상:** 큐에 "memory/ 폴더의 .md 파일을 표로 정리"를 시켰더니 7개가 아니라 2개만 정리하고 "완료 기준 충족"이라고 보고했다.

**원인:** [확인] 작업자(`claude -p`)의 컨텍스트에 별도의 "자동 메모리 폴더"가 있어, `memory/`를 그쪽으로 해석했다. 완료 판정도 자신이 만든 표 안에서만 맞춰 보아 틀린 대상을 못 걸러냈다.

**해결/방법:**
1. 프롬프트에 "상대 경로는 모두 이 워크스페이스 절대 경로 기준"을 명시하고, 헷갈리기 쉬운 같은 이름의 폴더를 이름으로 적어 제외한다.
2. 완료 판정 전에 대상 경로를 `ls` 등으로 직접 확인해 개수를 대조하라고 지시한다.
3. 목표에 "완료 기준"(검증 가능한 수치·파일)을 넣게 하고, 시험은 일부러 틀리기 쉬운 목표로 한 번 돌려 본다.

**일반화:** 사람이 응답할 수 없는 자동 작업자는 "완료"를 스스로 선언하므로, 대상 식별과 검증을 프롬프트로 강제하고 첫 실작업을 반드시 결과까지 열어 확인한다.

**근거:** 2026-11-23 큐 시험 2회(1차 2개 거짓 완료, 경로 규칙 추가 후 2차 7개 정상).
