# L-085 텔레그램 승인 UX: 내장 중계 + 답장 키보드

**상황/증상:** 발송·삭제 같은 행동을 텔레그램 버튼으로 승인받고 싶은데, 내 스크립트로 인라인 버튼을 보내도 눌렀을 때 받을 곳이 없다.

**원인:** [확인] 봇 토큰 하나에 `getUpdates` 소비자는 하나뿐이다(채널 플러그인이 점유). 버튼 콜백은 플러그인으로 가고, 플러그인은 자기 권한 요청 형식(`perm:...`)만 처리한다.

**해결/방법:**
1. 에이전트 세션 자신의 도구 승인은 플러그인 내장 권한 중계(Allow/Deny 버튼)를 쓴다. 작동은 시험 메시지 사이의 메시지 번호 차이로 확인했다.
2. 스크립트가 만든 승인은 `sendMessage`의 `reply_markup`에 답장 키보드(`승인 코드`/`거절 코드` 버튼)를 붙인다. 누르면 그 글자가 사용자 메시지로 들어오고, 세션이 코드를 검증해 결정 기록 스크립트를 호출한다.
3. 코드는 5글자 무작위, 대기 중일 때만 유효, 중복·없는 코드 거부, 48시간 뒤 만료. 승인은 요청에 적힌 행동 하나에만 해당한다.

**일반화:** 한 봇 토큰을 여러 소비자가 나눠 쓸 수 없으므로, 입력은 한 곳(채널)으로 모으고 버튼은 "눌러서 글자를 보내는 장치"로 쓴다.

**근거:** 2026-11-23 플러그인 소스(v0.0.7) 확인, 승인 흐름 시험(요청→승인→재개→완료)과 상시 세션의 코드 처리 시험 성공. 폰에서 버튼을 실제로 누르는 시험은 [미확인].
