# 예제 (일반화한 참고 코드)

이 폴더의 코드는 실제 운영 스크립트에서 **개인정보·경로·정책 원문을 걷어내고 일반화한** 것입니다. 그대로 복사하면 동작하도록 썼지만 **환경에 맞게 고쳐 써야** 하고, 아래 표의 "시험" 열만큼만 확인했습니다.

| 파일 | 하는 일 | 시험 |
|---|---|---|
| [`supervisor.sh`](supervisor.sh) | tmux 안에서 AI 세션을 항상 켜 두고 죽으면 다시 띄움, 매일 정해진 시각 재시작 | 문법 검사만, 실행 명령은 [미확인] |
| [`tg-lib.sh`](tg-lib.sh) | 텔레그램 Bot API로 텍스트 보내기(토큰은 권한 600 파일에서 읽음) | 문법 검사만 |
| [`run-daily.sh`](run-daily.sh) | 하루 2번 정기 실행기. 단계를 독립 실행하고, 사용 한도(종료 코드 75)면 해제 시각까지 기다려 1회 재시도(L-104) | 문법 검사 + 시각 파싱 시험 |
| [`write-guard.sh`](write-guard.sh) | 쓰기 직전 중복 검사 래퍼 패턴(L-100) | 문법 검사 + 논리 시험 |
| [`health-check.sh`](health-check.sh) | 자기 점검: "오늘 완료 기록"으로 판단, 같은 문제는 6시간에 한 번만 알림(L-104) | 문법 검사 + 시험 실행 |
| [`rotate-logs.sh`](rotate-logs.sh) | 분기별 로그 압축 + 총용량 보고(L-103) | 합성 로그 시험 통과 |
| [`backup.sh`](backup.sh) | 작업 폴더를 클라우드 폴더에 날짜별로 복사, 최근 N개 유지 | 실제 운영과 같은 방식으로 시험 |
| [`launchd/`](launchd) | 매일·분기 실행용 LaunchAgent 템플릿 | `plutil -lint` |

공통 규칙: 모든 스크립트는 `ASSISTANT_HOME`(기본 `~/assistant`) 아래에서 동작하고, 비밀은 코드에 넣지 않습니다.
